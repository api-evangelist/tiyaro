# Tiyaro

> Tiyaro is an enterprise AI company in San Francisco, founded 2021 and backed by General Catalyst. Its product, DeepQuery, replicates complete business processes as AI agents described in plain English, targeting customer support and IT service desks, revenue operations, and sales/marketing automation. Tiyaro goes to market through a book-a-demo motion. It has NO public developer API today: the AI model consumption platform it operated in 2021-2022 (api.tiyaro.ai, console.tiyaro.ai, docs.tiyaro.ai) has been decommissioned and all three hosts return NXDOMAIN as of 2026-08-14.

Generated by API Evangelist from apis.yml and the artifacts in this repository. Tiyaro does not publish an llms.txt of its own; https://www.tiyaro.ai/llms.txt returns HTTP 200 but serves the site's Gatsby HTML shell, not a document.

## Tooling

- [tiyaro on PyPI](https://pypi.org/project/tiyaro/): The only first-party client library. Ships a `tiyaro` CLI (init, push, test, infer, clean) and a model-handler SDK for publishing custom PyTorch models to the former Tiyaro platform. Last release 0.0.8 on 2022-05-31; the endpoints it calls no longer resolve.
